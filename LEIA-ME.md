# 🏆 Copa do Mundo FIFA 2026 — Calendário

Landing page com os 104 jogos da Copa para adicionar ao calendário do iPhone e Android em **um toque**.

## 📦 Como publicar no GitHub Pages (5 minutos)

1. **Crie um repositório novo** (ex.: `copa2026` ou `copamundo2026`).
2. Suba os dois arquivos na **raiz** do repositório:
   - `index.html`
   - `copa-mundo-2026.ics`
3. Ative o GitHub Pages: **Settings → Pages → Source: main branch → root → Save**.
4. Em 1–2 minutos, sua URL fica disponível:
   `https://lucasbessoni.github.io/copa2026/`
5. (Opcional) Configure um link curto via Rebrandly: `bfadv.link/copa2026`.

## 📲 Como compartilhar pelo WhatsApp

Mande apenas o **link da página** (não o arquivo `.ics`):

```
https://lucasbessoni.github.io/copa2026/
```

ou, se usar o Rebrandly:

```
https://bfadv.link/copa2026
```

### O que acontece quando alguém clica:

| Dispositivo | Comportamento |
|---|---|
| 📱 **iPhone / iPad** | Página detecta iOS → botão usa `webcal://` → ao tocar, o app Calendário abre direto pedindo "Inscrever". **Instalação em 1 toque.** |
| 🤖 **Android** | Página detecta Android → botão abre o Google Agenda Web pedindo confirmação → após inscrever, sincroniza automaticamente com o app no celular. |
| 💻 **Desktop** | Botão faz download direto do `.ics` para abrir no app de calendário preferido. |

## ✨ Recursos do calendário

- **104 jogos** com data, horário (Brasília — BRT) e estádio
- **Alerta automático** 1 hora antes de cada partida
- **Bandeira de cada seleção** no título do evento (emoji)
- **Mando de campo, grupo e número do jogo** no campo de descrição
- **Crédito** ao Instagram @bessoni.lucas em cada evento

## 🔄 Atualizações futuras

Quando a FIFA confirmar os horários definitivos da fase eliminatória (oitavas, quartas, semifinais e disputa de 3º lugar), basta:

1. Atualizar os horários no script gerador
2. Substituir o arquivo `copa-mundo-2026.ics` no repositório

Como o calendário foi **assinado** (não importado), todos os assinantes recebem as atualizações automaticamente no celular.
